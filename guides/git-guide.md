# Гайд по гиту

## Именование веток

Ветку именуем по следующему шаблону:

```
{фамилия/никнейм/любой идентификатор}/NOT-{номер задачи}/{название фичи}
```

Например: `goncharov/NOT-31/md-files`

## Husky

Husky обязателен к использованию. Хуки, настроенные в `.husky`, должны быть активны у каждого участника команды и не должны отключаться или обходиться (`--no-verify` запрещён).

## Пулл-реквесты

* После пуша в гит обязательно составляется ПР (пулл реквест).
* Описание ПР должно содержать ссылку на задачу.
* ПР проверяется всеми участниками команды Фронтенд.
* Мёрж в ветку `main` делается создателем ПР.
* Разрешение конфликтов также является ответственностью создателя ПР.
